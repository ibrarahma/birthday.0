# Mubeen ka Birthday Surprise 💗

Ibrar ki taraf se Mubeen ke liye cute birthday website. HTML, CSS aur JavaScript se bani hai.

## Password
Default password `2011` hai. `script.js` mein `const PASSWORD = "2011";` edit karke badal sakte ho. Yeh fun gate hai, real security nahi.

## GitHub Pages
1. Files ko public GitHub repository ke root mein upload karo.
2. **Settings → Pages → Deploy from a branch** select karo.
3. Branch `main`, folder `/(root)` select karke **Save** dabao.
4. Pages section mein live URL milega.

Photos gallery mein select ki gayi photos sirf current browser session mein dikhengi; automatically upload nahi hoti. GitHub Pages public hoti hai, isliye private photos ya sensitive info publish mat karo.


Music feature: removed as requested. The website keeps the gift ring, promise form, love letter, photo gallery, and birthday cake.
